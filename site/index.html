Same subscription, two ways in.

Point an OpenAI-compatible client at one door, or an MCP client at the other. Both end up in the same queue.

OpenAI-compatible API

/v1

Use it from anything that speaks the OpenAI chat format, including @ai-sdk/openai-compatible.

  • POST /v1/chat/completionschat
  • GET /v1/modelsmodels
  • Streaming with stream: true, SSE chunks in OpenAI formatSSE
  • Token usage in the last chunk with include_usageusage
curl https://connector.your-domain.com/v1/chat/completions \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gemini-3.8-flash",
       "reasoning_effort":"low",
       "messages":[{"role":"user",
         "content":"Say hello in one word."}]}'

MCP server

/mcp

Streamable HTTP, for any MCP client: Claude, Cursor, Codex and others. Progress is reported while a call waits and runs, and a cancelled call kills the agy process.

  • web_searchlinks · ~20 to 45 s
  • generate_imageone PNG · ~1 min
  • researchreport with sources · minutes
  • browseread a public page
  • Progress during queue and run, when the client sends a progress tokenprogress
# in your client's MCP settings
{
  "mcpServers": {
    "antigravity": {
      "url": "https://connector.your-domain.com/mcp",
      "headers": {
        "Authorization": "Bearer <API_KEY>"
      }
    }
  }
}

Every call takes the same four steps.

  1. 01

    The request arrives

    Every route except /health needs the Bearer token. In Docker the app publishes its port on 127.0.0.1 only; an HTTPS proxy on 443 sits in front of it.

    API_KEY
  2. 02

    It waits its turn

    Up to four agy calls run at once. API and MCP calls share the same queue, with a limit on how long a call may wait.

    QUEUE_CONCURRENCY
  3. 03

    agy runs it

    Each call executes the official Antigravity CLI as a subprocess. The server never reads, copies or forwards the CLI login token, and never calls Google directly.

    AGY_TIMEOUT_MS
  4. 04

    The answer comes back

    SSE chunks for chat, progress notifications for MCP. If the client cancels, the agy process is stopped.

    stream: true

Small on purpose. Limits live in the server.

4calls at once Concurrency

Past four runs at once, calls wait in line instead of racing the CLI.

24chars API_KEY minimum
300s Call timeout, default
120s Queue wait, default

Daily limits per call type (chat, search, image, research and browse) and per-minute request limits are set with DAILY_LIMIT_* variables. MCP sessions default to a maximum of 8.

Four commands, then log in once.

~/antigravity-connector 
$ cp .env.example .env                 # set API_KEY, at least 24 characters
$ docker compose up -d --build
$ curl -H "Authorization: Bearer $API_KEY" http://127.0.0.1:8787/v1/auth    # login link, if needed
$ curl https://connector.your-domain.com/health

On your VPS, one docker command.

your VPS: the port stays on 127.0.0.1
$ docker run -d --name antigravity-connector --restart unless-stopped \
    -p 127.0.0.1:8787:8787 \
    -e API_KEY='your-random-api-key-at-least-24-chars' \
    -v agy-gemini:/home/agy/.gemini -v agy-data:/data \
    ghcr.io/guilhermebkel/antigravity-connector:latest
$ curl -H "Authorization: Bearer $API_KEY" https://connector.your-domain.com/v1/auth    # login link, open it and sign in
$ curl -X POST -H "Authorization: Bearer $API_KEY" \
    -H "Content-Type: application/json" -d '{"code":"..."}' https://connector.your-domain.com/v1/auth
$ curl https://connector.your-domain.com/health

Login happens in the terminal

There is no web page. GET /v1/auth returns a login link; sign in, copy the code, and send it to POST /v1/auth within 60 seconds. The same two calls exist as MCP tools, check_auth and set_auth.

It survives restarts

The login lives in the named volume agy-gemini. docker compose down -v removes it, and you log in again.

Check it works

/health is the only route without the token. Everything else expects Authorization: Bearer.

What it does not do, and what could go wrong.

  • Not yetTool calling. The tools field returns 400.
  • Not yetPDF and other file input, audio and video, and a browser profile with your own logins.
  • Ignoredtemperature and max_tokens are accepted but have no effect.
  • PinnedThe agy binary is fixed at version 1.5.9 in the image.

Read this before you run it

Using a subscription through a local tool is not documented by Google for the CLI.

  • Terms, limits and the CLI itself may change.
  • A call can fail or be refused.
  • Meant for personal use, at low volume.
  • Keep the API key secret.

Start on your VPS.
